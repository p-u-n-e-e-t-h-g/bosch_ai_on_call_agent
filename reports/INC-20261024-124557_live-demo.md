# INC-20261024-124557 — live-demo

**Alert:** Operation GET /api/products/index on frontend failing: error rate 14%; Operation POST /api/checkout on frontend failing: error rate 20%  
**Final status:** escalated  
**Root cause:** `product-catalog` — crash_loop  
**Confidence:** 0.95 (agent stated 0.95)

The product-catalog container restarted due to high memory usage reaching its 20MiB limit (99.1% memory utilization). During the container restart, requests from frontend and checkout to ProductCatalogService failed with ECONNREFUSED/ECONNRESET, causing 500 errors on GET /api/products/index and POST /api/checkout.

## Root cause
The product-catalog service restarted due to memory pressure under its tight 20MiB memory limit (reaching 99.1% utilization). While product-catalog was restarting, downstream gRPC requests from frontend and checkout failed with ECONNREFUSED, ECONNRESET, and EOF errors, resulting in elevated error rates on GET /api/products/index and POST /api/checkout.
